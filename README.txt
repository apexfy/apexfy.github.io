APEXFY - FREE PUBLISHING (GitHub Pages)
1. Create a free account at github.com
2. New repository, name it: apexfy (Public)
3. Upload ALL files in this folder (Add file > Upload files)
4. Settings > Pages > Source: "Deploy from a branch" > main > / (root) > Save
5. After ~1 minute your app is live at https://YOUR-USERNAME.github.io/apexfy/
6. Google: go to search.google.com/search-console, add that URL, then "URL inspection" > "Request indexing"
